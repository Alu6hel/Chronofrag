Overview
Aura FM (Artificial Modulation / Fluid Music) is a localized, generative radio application designed for warmth and personality. It replaces the traditional static playlist with an endless, dynamically generated audio stream. Instead of a sterile recommendation algorithm, your music is curated and hosted by a highly responsive AI personality, bridging the gap between passive listening and an interactive, deeply personal audio experience.

Core Features
The Synth-Host: Utilizing local text-to-speech engines like Qwen-TTS and LuxTTS, the app builds a friendly, lifelike radio host. The DJ smoothly introduces tracks, provides context on lyrical compositions, and generates conversational, localized banter.

Tactile DSP Tuning: A clean virtual dial controls real-time digital signal processing. Listeners can adjust the master EQ, inject analog tape warmth, or apply custom spatial effects like reverb and delay to simulate the atmospheric echo of a late-night broadcast.

Generative Audio Pipeline: The application seamlessly streams local libraries while interweaving AI-assisted instrumental tracks, allowing for uninterrupted blocks of structured hip-hop arrangements, lo-fi, and electronic beats.

High-Demand Concepts
Granular Mood Sliders: Listeners want more than just a skip button. Aura FM provides intuitive parametric sliders for "Energy," "Lyrical Complexity," or "Nostalgia" to algorithmically fine-tune the station's vibe on the fly.

Intelligent Audio Ducking: The host AI doubles as an embedded personal assistant, seamlessly lowering (ducking) the instrumental volume to announce your upcoming calendar events or breaking daily alerts directly over the airwaves.

Fully Offline Mode: The capability to pre-generate caching blocks ensures a flawless, continuous listening experience, keeping the music playing even when internet connectivity drops.

Technical Architecture
Bare-Metal Audio Engine: To prevent playback stutter while handling heavy real-time effects, the core audio routers are written in low-level systems languages like Rust and Zig.

Local AI Integration: The infrastructure is optimized to run alongside local LLM environments like Ollama, ensuring zero-latency text generation and keeping the DJ completely responsive and private.
